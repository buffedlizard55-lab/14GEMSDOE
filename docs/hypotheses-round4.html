Round 4: distinct research candidates

These are pre-registered hypotheses, not proven predictors. Each uses a physical signature not implemented in the current feature arms, and each is ranked qualitatively. No model change or submission is authorized without a real, spatially-blocked holdout win.

Decision: HOLD — no candidate is slot-eligible. This checkout contains no competition rasters/labels/template or DEM links; its Python runtime lacks NumPy, SciPy, rasterio and pytest. Round-2/3 measurements are synthetic and cannot be interpreted as leaderboard scores.

1R4A — joint geophysical boundary topology.
Competition stack: isostatic gravity anomaly/slope; RTP/TMI and magnetic slopes; surface conductivity and depth to conductive base. Target multi-field edge co-location, compatible strike, and edge termination/gap continuity.		Subsurface basin-fill faults can lack scarps while juxtaposing physical contrasts. A joint edge topology may retain a candidate where one field is weak. Existing N1 is gravity-only endpoints; R3C is magnetic-only fabric; N3 is a thresholded conductivity/magnetic cap mask. R4A combines these sources at the edge/topology level. Coincident anomalies are not automatically faults.Medium, high uncertainty / medium cost / no new external source. Real stack absent.
2R4B — hydrographic deflection/offset.
USGS 3DEP bare-earth DEM where available plus USGS 3DHP flowlines. Target channel bends, abrupt offsets and aligned knickpoints with shared strike.		Fault displacement can deform channels even when a coherent scarp is absent. A peer-reviewed mapping study documents fault-related deflected streams (Geosphere 2012); a USGS trench study documents a stream deflection with a nontectonic cause, so this is not diagnostic alone. Unlike existing slope/range-front (N5) or curvature-scarplet (R3D) features, this models network geometry. Screen lithology, drainage capture, infrastructure and raster artefacts.Medium, high uncertainty / high cost / 3DEP and 3DHP are official sources, but exact GeoDAWN coverage not verified.
3R4C — geologic-contact offset graph.
USGS/Nevada geologic-map contacts and unit polygons. Target repeated contact truncation/offset on a shared lineament.		A concealed fault may offset units without being in the fault catalogue. No current feature uses geologic unit polygons/contact networks. Map scale, date, and existing fault overlays are major leakage and accuracy risks.Medium, high uncertainty / high cost / regional USGS Data Series 249 exists at 1:250,000; adequacy for 100 m fault placement is unproven.
4R4D — signed alternating scarp polarity.
Competition 1 m DEM / 3DEP. Target aligned uphill- and downhill-facing small scarps in a repeated sequence, not an unsigned curvature ridge.		Could represent discontinuous strike-slip microtopography missed by a catalogue. Distinct from N5 slope threshold and R3D negative-curvature linkage, but shares the broader terrain evidence family and is vulnerable to nontectonic scarps.Low-to-medium, high uncertainty / medium-high cost / local DEM coverage not verified.

Source checks for manual review

  • DrivenData provided-feature list — official layer names; actual TIFF band tags remain unavailable here.
  • USGS Great Basin integrated play-fairway report — multiple geologic/geophysical observations at blind geothermal systems; this supports integration, not a predicted DTI gain.
  • USGS Argenta Rise study — basin-fill-obscured structures and joint gravity/magnetic/MT interpretation.
  • USGS 3DEP and National Map downloads — official elevation/data access routes.
  • USGS 3DHP — official hydrography program; region-specific product coverage still must be checked.
  • USGS/AASG NGMDB MapView and USGS Data Series 249 — map discovery/download source and regional map description. DS249 documents 1:250,000 scale, not 100 m local accuracy.
  • USGS Nevada geothermal data release — public record for regional geophysics, heat-flow, slip and dilation products; a heat-flow-gradient candidate was not ranked because earlier H3 already proposed heat-flow evidence.
  • Live public leaderboard — fetched 2026-09-28; DARD was at 0.3168 at that check. Public leaderboard values are not comparable with this repo's synthetic holdout values.

Gate protocol

  1. Acquire authorized competition data and record file hashes, CRS, shape, transforms, no-data mask, and all band tags. The DrivenData data tab is login-gated. Dropbox links supplied in the project brief are team-provided shares, not authenticated official mirrors; SHA256 only records bytes, not provenance.
  2. Use the same geographic block folds, purge buffer, and hide-and-recover process for the incumbent and candidate. No label-derived transforms may see held-out labels.
  3. Report discovery/recovery/combined DTI by fold and seed with uncertainty; compare against a real-data incumbent. Literature and synthetic tests do not qualify a candidate for a submission slot.
  4. Only after a real holdout win: validate the generated TIFF against the official template, compare full prediction-array hashes with every prior artifact, then decide whether a competition slot is justified.
