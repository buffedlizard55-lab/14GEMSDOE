E · Irregularities flagged for review

  1. #1 Sandbox network policy: direct TLS downloads from dropbox.com, gdr.openei.org files, sciencebase.gov and docs.nlr.gov are blocked in the Arena sandbox (handshake closed). Page content is reachable and was used for all verification. Binary acquisition is scripted (scripts/download_*.sh) for an unrestricted machine. Team-shared Dropbox mirrors were therefore not re-hashed here — the scripts hash whatever is downloaded and record it.
  2. #2 Structural-setting percentages drift across vintages (32/22/22/8 in the 2012 catalogue vs 25/20/18/7 in the later 313-system classification). The brief's numbers are the 2012 catalogue and are correct for that source; hypotheses are robust to the drift (the same four settings dominate every vintage).
  3. #3 Stale leaderboard figure in the working brief (“0.3049 is the highest score right now”): the verified live top score on 2026-09-28 is 0.3168; 0.3049 is not in the top 50.
  4. #4 “Geothermal vents” vs the actual target: the brief sometimes frames the goal as “discovery of geothermal vents”; the competition's scored target is faults (structures indicative of geothermal resources). Volcanic vents are used here only as an independent structure proxy (H3), never as labels.
  5. #5 Masking semantics ambiguity: the staff ruling says known-fault pixels are “excluded from evaluation”; whether a prediction on a masked pixel can still earn kernel credit for a nearby hidden pixel is not spelled out. The implementation excludes masked pixels from both sides (the only reading under which “it should not matter” is exactly true) and keeps the alternative as a documented sensitivity switch.
  6. #6 19-band order: the problem description lists 19 named layers but not the band order; scripts/prepare_data.py reads the data dictionary shipped with the download when present and refuses to guess otherwise.
