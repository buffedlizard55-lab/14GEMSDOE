Round 7 — the problem statement told us where the truth is

Two official statements reframe what the hidden labels contain. C28 (problem description): "portions of the existing fault data may be misaligned from the true location of the surface fault, which is the prediction target" — the scored truth is the true trace, not the catalogued raster. C21 (staff): a "new fault" can be "newly mapped geometry of an existing fault system — a continuation past a mapped tip, a splay, a parallel strand". No arm in R1–R6 models misregistration or buried continuation. Round 7 starts there. No submission slot is spent by any round-7 arm until it beats the holdout best.

Re-test notice: R7-3 is N1's physics (gravity-gradient terminations/intersections, the label producers' own basin playbook — KB S11). N1's only evidence is a synthetic-model kill, which the session-14 directives state is not evidence. It has never run against the real rasters. A null on real data kills it for good.
